# Excel Fundamental Boosters

## Project Overview
Excel Fundamental Boosters is a practice project designed to improve Microsoft Excel skills through three different datasets: Students Data, Sales Data, and Employee Data.

This project covers basic to intermediate Excel functions, including mathematical calculations, logical functions, lookup functions, text functions, and date functions.

## Worksheets Included

### 1. Students Data
This worksheet contains student IDs, names, marks in Math, Science and English, and enrollment dates.

**Functions Used:**
- AVERAGE – Calculates students' average marks.
- IF – Assigns grades based on average marks.
- AND – Checks multiple conditions.
- Nested IF – Applies multiple grading conditions.

### 2. Sales Data
This worksheet contains sales IDs, products, regions, salespeople, sales amounts, dates, discount rates, discount amounts, and net sales.

**Functions Used:**
- IF – Applies conditions to calculate discounts.
- OR – Checks multiple conditions.
- SUM – Calculates total sales.
- AVERAGE – Calculates average sales.
- SUMIF – Calculates sales based on one condition.
- SUMIFS – Calculates sales based on multiple conditions.
- VLOOKUP – Searches for specific information.
- INDEX and MATCH – Retrieves values based on matching criteria.

### 3. Employee Data
This worksheet contains employee IDs, names, departments, salaries, joining dates, and employee-related calculations.

**Functions Used:**
- YEAR – Extracts the year from a date.
- DATEDIF – Calculates years of service.
- UPPER – Converts text into uppercase.
- LOWER – Converts text into lowercase.
- LEFT – Extracts characters from the left side of text.
- FIND – Finds the position of a character or text.
- INDEX and MATCH – Searches for employee information.
- FLOOR – Rounds a number down to a specified multiple.
